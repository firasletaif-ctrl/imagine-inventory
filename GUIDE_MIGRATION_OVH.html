🚀 Migration Render a OVH

Tunisie Imagine Events Tunisia - Guide complet pour la personne OVH

Duree : 20 minutes
Prerequis : Serveur Ubuntu 22.04/24.04, Domaine pointe, Acces SSH root
Fichier : Imagine_Inventory_v2.zip

Avant de commencer

✅Serveur OVH accessible en SSH
✅Ubuntu 22.04 ou 24.04 installe
✅Nom de domaine pointant vers l'IP du serveur
✅Code a jour sur GitHub (firasletaif-ctrl/imagine-inventory)

Etape 1 - Connexion SSH

1

Se connecter

ssh root@IP_DU_SERVEUR

L'IP et le mot de passe sont dans l'espace client OVH.

Etape 2 - Installation automatique

2

Cloner et lancer le script

cd /var/www && git clone https://github.com/firasletaif-ctrl/imagine-inventory.git && cd imagine-inventory && bash install.sh
⚠️ Avant : modifie les 5 premieres lignes de install.sh : DOMAIN, DB_USER, DB_PASS, SECRET_KEY, ADMIN_EMAIL

Etape 3 - Emails

3

Configurer Brevo

Edite /etc/supervisor/conf.d/imagine.conf et ajoute dans la ligne environment= :

SMTP_PASSWORD="xkeysib-...",SMTP_FROM="votre-email@imagine-events.tn"

Puis : supervisorctl reread && supervisorctl restart imagine

Etape 4 - Donnees

4

Option A : Demarrer a zero

Base creee automatiquement : admin@imagine-events.com / admin123 + 8 articles

Option B : Migrer depuis Render

Voir le guide GUIDE_SAUVEGARDE.html dans le ZIP.

Etape 5 - Verifier

5

Checklist

✅Connexion admin
✅Dashboard + materiel
✅Ajout materiel + photos
✅Emprunt / Retour
✅Planning + hotels
✅Notifications
✅Export Excel / PDF
✅Gestion utilisateurs + roles
✅Logs d'activite
✅HTTPS (certbot)

Commandes utiles
