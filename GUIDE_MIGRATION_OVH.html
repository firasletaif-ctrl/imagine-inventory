✅ Accès SSH root au serveur
✅ Le fichier Imagine_Inventory_Deploy.zip

Étape 1 — Se connecter au serveur OVH

1

Connexion SSH

Depuis votre PC Windows, utilisez PowerShell ou téléchargez PuTTY :

ssh root@IP_DE_VOTRE_SERVEUR

👉 L'IP se trouve dans votre espace client OVH → rubrique "Serveur"

👉 Le mot de passe root a été envoyé par email OVH à l'installation du serveur.

Étape 2 — Installer les dépendances

2

Tout installer d'un coup

Copiez-collez ce bloc entier dans le terminal :

apt update && apt upgrade -y apt install -y python3 python3-pip python3-venv python3-dev \\ postgresql postgresql-contrib \\ nginx supervisor \\ git build-essential libpq-dev

⏱️ ~3 minutes

Étape 3 — Configurer PostgreSQL

3

Créer la base de données

# Passer en utilisateur postgres sudo -u postgres psql

Puis dans la console psql, tapez ces 4 commandes une par une :

CREATE USER imagine_user WITH PASSWORD 'Imagine2026!Secured'; CREATE DATABASE imagine_inventory OWNER imagine_user; GRANT ALL PRIVILEGES ON DATABASE imagine_inventory TO imagine_user; \q

👉 Remplacez Imagine2026!Secured par votre propre mot de passe fort.

👉 \q pour quitter.

Étape 4 — Déployer le code

4

Créer le dossier et déployer

Méthode A : Via GitHub (recommandée)

# Cloner votre repo GitHub mkdir -p /var/www cd /var/www git clone https://github.com/firasletaif-ctrl/imagine-inventory.git cd imagine-inventory

Méthode B : Upload manuel

# Sur votre PC, avec PowerShell : scp Imagine_Inventory_Deploy.zip root@IP_SERVEUR:/var/www/ # Puis sur le serveur : cd /var/www && unzip Imagine_Inventory_Deploy.zip mv imagine-deploy imagine-inventory && cd imagine-inventory

 

Installer les dépendances Python :

python3 -m venv venv source venv/bin/activate pip install -r requirements.txt pip install gunicorn psycopg2-binary

Créer le fichier d'environnement :

cat > .env << 'EOF' DATABASE_URL=postgresql://imagine_user:Imagine2026!Secured@localhost:5432/imagine_inventory SECRET_KEY=VotreCleTresLongueEtSecrete123! EOF

Créer le dossier uploads :

mkdir -p uploads && chmod 755 uploads

Étape 5 — Supervisor (garder l'app en vie)

5

Créer le fichier de configuration

cat > /etc/supervisor/conf.d/imagine.conf << 'EOF' [program:imagine] command=/var/www/imagine-inventory/venv/bin/gunicorn app:app --bind 127.0.0.1:8000 --workers 3 --timeout 120 directory=/var/www/imagine-inventory user=www-data autostart=true autorestart=true stdout_logfile=/var/log/imagine.log stderr_logfile=/var/log/imagine-error.log environment=DATABASE_URL="postgresql://imagine_user:Imagine2026!Secured@localhost:5432/imagine_inventory",SECRET_KEY="VotreCleTresLongueEtSecrete123!" EOF

Puis :

supervisorctl reread supervisorctl update supervisorctl start imagine supervisorctl status imagine # Doit dire RUNNING

Étape 6 — Nginx (serveur web)

6

Créer la configuration du site

cat > /etc/nginx/sites-available/imagine << 'EOF' server { listen 80; server_name depot.imagine-events.tn; # ← VOTRE DOMAINE client_max_body_size 16M; location / { proxy_pass http://127.0.0.1:8000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } location /uploads/ { alias /var/www/imagine-inventory/uploads/; } } EOF

Activer le site :

ln -s /etc/nginx/sites-available/imagine /etc/nginx/sites-enabled/ rm -f /etc/nginx/sites-enabled/default # Optionnel : désactiver le site par défaut nginx -t # Vérifier la syntaxe systemctl reload nginx
Votre site est maintenant accessible sur http://depot.imagine-events.tn 🎉

Étape 7 — HTTPS gratuit (SSL)

7

Certificat SSL avec Let's Encrypt

apt install -y certbot python3-certbot-nginx certbot --nginx -d depot.imagine-events.tn

👉 Entrez votre email → Acceptez les conditions → Choisissez "Redirect" (option 2)

✅ Votre site est maintenant en HTTPS ! Le certificat se renouvelle automatiquement.

Étape 8 — Migrer les données de Render

8

Option 1 : Recommencer à zéro (recommandé si peu de données)

La base se réinitialise automatiquement au premier démarrage avec :

👑 Adminadmin@imagine-events.comadmin123
👷 Staffstaff@imagine-events.comstaff123

+ 8 matériels de test.

Option 2 : Exporter depuis Render

Sur votre Web Service Render → onglet Shell :

pg_dump $DATABASE_URL > backup.sql

Puis téléchargez backup.sql et importez sur OVH :

psql postgresql://imagine_user:Imagine2026!Secured@localhost:5432/imagine_inventory < backup.sql

Étape 9 — Vérifier

9

Tests finaux

# Vérifier que Supervisor fait tourner l'app supervisorctl status imagine # → imagine RUNNING pid 12345, uptime 0:05:00 # Vérifier Nginx systemctl status nginx # → Active: active (running) # Vérifier que le site répond curl -I https://depot.imagine-events.tn # → HTTP/2 200

Puis ouvrez https://depot.imagine-events.tn dans votre navigateur !
