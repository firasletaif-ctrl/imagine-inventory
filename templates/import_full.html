⬆️ Import complet — 1 clic

Restaure tout le site à partir d'une sauvegarde complète : articles, catégories, comptes, événements, emprunts, photos, historique… dans le bon ordre, en une seule opération.

Comment faire

  1. Sur l'ancien site (ou le site à sauvegarder) : bouton 💾 Sauvegarde complète (menu Export) → le fichier imagine_backup_…​.zip se télécharge.
  2. Ici : choisis ce fichier ci-dessous, entre ton mot de passe, clique sur « ⬆️ Importer tout ».
  3. C'est tout. Les données déjà présentes (même numéro) sont mise à jour, le reste est ajouté. Rien n'est supprimé.

⏱️ Selon la taille du fichier (photos comprises), l'import peut prendre 1 à 3 minutes — laisse la page travailler sans la fermer. Un récapitulatif détaillé s'affichera à la fin.
