🚀 Déploiement Imagine Inventory — Guide Pas à Pas

🇹🇳 Imagine Events Tunisia — Digitalisation du dépôt événementiel

⏱️ Durée totale : 10-15 minutes
💰 Coût : 0 DT (Gratuit — plan Free de Render)
📋 Prérequis : Un navigateur web et le fichier ZIP du projet

PARTIE 1 : RENDER (phase de test gratuite)

1

Créer un compte Render

  1. Allez sur 👉 render.com
  2. Cliquez "Get Started" (bouton bleu en haut à droite)
  3. Inscrivez-vous avec votre email ou votre compte GitHub
  4. Vérifiez votre email si demandé
2

Créer la base de données PostgreSQL

  1. Dans le dashboard, cliquez "New +" → "PostgreSQL"
  2. Remplissez :
    • Name : imagine-events-db
    • Region : Frankfurt (EU) — le plus proche de la Tunisie
    • Plan : Free
  3. Cliquez "Create Database"
⚠️ IMPORTANT : Une fois créée, descendez dans Connections → Internal Database URL et COPIEZ cette URL. Elle ressemble à :
postgres://imagine_events_db_user:xxxxx@dpg-xxxxx/imagine_events_db
Gardez-la précieusement !
3

Créer le Web Service

  1. Cliquez "New +" → "Web Service"
  2. Choisissez "Public Git repository"
  3. Ou plus simple : cliquez "Deploy from a Git repository" puis en bas "Or deploy from a public repository"
4

Configurer le Web Service

Remplissez le formulaire comme ceci :

Nameimagine-inventory
RegionFrankfurt (EU)
Branchmain
RuntimePython 3
Build Commandpip install -r requirements.txt
Start Commandgunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120
PlanFree
5

Ajouter les variables d'environnement

Dans la section "Environment Variables", ajoutez :

CléValeur
DATABASE_URL← Collez l'URL PostgreSQL de l'étape 2
SECRET_KEYimagine2026!MonSecretTunisie
6

Déployer !

Cliquez "Create Web Service" tout en bas.

Render va :

  1. 📥 Télécharger votre code
  2. 📦 Installer les dépendances Python
  3. 🗄️ Connecter la base PostgreSQL
  4. 🚀 Lancer l'application

⏳ Patientez 3-5 minutes le temps du déploiement. Vous verrez "Live" en vert.

🌐 Votre site sera accessible à l'URL : https://imagine-inventory.onrender.com

7

Première connexion

Allez sur votre URL et connectez-vous :

RôleEmailMot de passe
Adminadmin@imagine-events.comadmin123
Staffstaff@imagine-events.comstaff123
⚠️ Changez ces mots de passe dès la première connexion !

PARTIE 2 : DÉPLOIEMENT SUR OVH (votre serveur)

Prérequis OVH : Un VPS ou serveur dédié avec Ubuntu/Debian, accès SSH root.
1

Se connecter au serveur OVH en SSH

ssh root@votre-ip-ovh
2

Installer les dépendances système

apt update && apt upgrade -y
apt install -y python3 python3-pip python3-venv nginx postgresql postgresql-contrib supervisor
3

Configurer PostgreSQL

sudo -u postgres psql -c "CREATE USER imagine_user WITH PASSWORD 'VotreMotDePasseFort';"
sudo -u postgres psql -c "CREATE DATABASE imagine_inventory OWNER imagine_user;"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE imagine_inventory TO imagine_user;"
4

Déployer l'application

mkdir -p /var/www/imagine-inventory
cd /var/www/imagine-inventory
# Uploadez vos fichiers (via SCP, FTP, ou Git)
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install gunicorn psycopg2-binary
5

Créer le fichier d'environnement

cat > /var/www/imagine-inventory/.env << 'EOF'
DATABASE_URL=postgresql://imagine_user:VotreMotDePasseFort@localhost:5432/imagine_inventory
SECRET_KEY=VotreCleSecreteTresLongue
EOF
6

Configurer Supervisor (pour que l'app tourne en continu)

cat > /etc/supervisor/conf.d/imagine.conf << 'EOF'
[program:imagine]
command=/var/www/imagine-inventory/venv/bin/gunicorn app:app --bind 127.0.0.1:8000 --workers 3
directory=/var/www/imagine-inventory
user=www-data
autostart=true
autorestart=true
environment=DATABASE_URL="postgresql://imagine_user:VotreMotDePasseFort@localhost:5432/imagine_inventory",SECRET_KEY="VotreCleSecrete"
EOF

supervisorctl reread
supervisorctl update
supervisorctl start imagine
7

Configurer Nginx (serveur web)

cat > /etc/nginx/sites-available/imagine << 'EOF'
server {
listen 80;
server_name depot.imagine-events.tn; # ← votre domaine

client_max_body_size 16M;

location / {
proxy_pass http://127.0.0.1:8000;
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

location /uploads/ {
alias /var/www/imagine-inventory/uploads/;
}
}
EOF

ln -s /etc/nginx/sites-available/imagine /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
8

Configurer le SSL (HTTPS gratuit)

apt install -y certbot python3-certbot-nginx
certbot --nginx -d depot.imagine-events.tn
9

Redémarrer et vérifier

supervisorctl restart imagine
systemctl restart nginx
# Votre site est en ligne ! 🎉

📁 Fichiers à déployer

Le ZIP Imagine_Inventory_Deploy.zip contient tout le nécessaire :
