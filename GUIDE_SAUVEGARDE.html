🔄 Guide Migration Base de Données

🇹🇳 Imagine Events Tunisia — Tous les 80-90 jours

⏰ Fréquence : Tous les 80 jours (la base Render gratuite expire après 90 jours)
⏱️ Durée : ~20 minutes
🎯 Objectif : Créer une nouvelle base propre et y remettre toutes les données
⚠️ Calendrier : Mets un rappel dans ton téléphone tous les 80 jours !

PARTIE 1 — SAUVEGARDER (15 min)

1

Sauvegarder les photos (1 clic)

  1. Connecte-toi à ton site Imagine Inventory en tant qu'Admin
  2. Dans la sidebar gauche → section 📤 Export
  3. Clique sur 📸 Photos (ZIP)
  4. Un fichier photos_imagine_XXXXXXXX.zip se télécharge
  5. Garde-le sur ton PC (Bureau ou dossier "Sauvegarde Imagine")
✅ Toutes les photos sont dans ce fichier ZIP. Ne le perds pas !
2

Ouvrir Beekeeper

Ouvre Beekeeper Studio et connecte-toi à ta base de données (External Database URL).

3

Exporter les tables (une par une)

Fais ceci pour CHAQUE table ci-dessous :

  1. Clic droit sur la table → "Export Table"
  2. Format : CSV
  3. Nomme le fichier comme la table (ex: users.csv)
  4. Sauvegarde dans ton dossier "Sauvegarde Imagine"
rolesRôles et permissions
usersUtilisateurs
categoriesCatégories de matériel
equipmentMatériel
equipment_imagesNoms des photos
borrowsEmprunts
eventsÉvénements
event_assignmentsAssignations
activity_logsLogs d'activité
notificationsNotifications
✅ 10 fichiers CSV dans ton dossier de sauvegarde. C'est tout ton travail qui est protégé !

PARTIE 2 — CRÉER LA NOUVELLE BASE (3 min)

4

Supprimer l'ancienne base

  1. Va sur dashboard.render.com
  2. Clique sur ta base PostgreSQL (ex: imagine-db-xxx)
  3. Tout en bas → section rouge "Danger Zone" → "Delete Database"
  4. Confirme en tapant le nom de la base
⚠️ Ne t'inquiète pas : tes données sont déjà sauvegardées dans les CSV !
5

Créer la nouvelle base

  1. New + → PostgreSQL
  2. Name : imagine-db-v5 (ou n'importe quel nom)
  3. Region : Frankfurt
  4. Plan : Free
  5. Clique "Create Database"
  6. Une fois créée, copie l'Internal Database URL
6

Reconnecter le Web Service

  1. Clique sur ton Web Service (imagine-inventory)
  2. Onglet "Environment"
  3. Trouve la variable DATABASE_URL
  4. Remplace sa valeur par la nouvelle Internal URL (copiée à l'étape 5)
  5. Clique "Save Changes"
  6. Render redéploie automatiquement (3-5 min)
⏳ Attends le déploiement. Quand tu vois 🟢 Live, passe à la partie 3.

PARTIE 3 — RÉIMPORTER (10 min)

7

Restaurer les photos

  1. Connecte-toi au site → sidebar → 📥 Restaurer photos
  2. Sélectionne le fichier photos_imagine_XXXXXXXX.zip sauvegardé à l'étape 1
  3. Clique "Restaurer les photos"
✅ Toutes les photos sont de nouveau sur le serveur !
8

Reconnecter Beekeeper à la nouvelle base

  1. Dans Beekeeper, déconnecte-toi de l'ancienne base
  2. Sur Render, dans la nouvelle base → onglet "Connections"
  3. Copie l'External Database URL
  4. Dans Beekeeper : nouvelle connexion → PostgreSQL → onglet "Connection String" → colle l'URL → Connect
9

Importer les tables dans l'ordre

⚠️ L'ordre est TRÈS IMPORTANT ! Fais-le dans cet ordre exact :

  1. roles → Clic droit → Import → choisis roles.csv
  2. users → Clic droit → Import → choisis users.csv
  3. categories → Import categories.csv
  4. equipment → Import equipment.csv
  5. equipment_images → Import equipment_images.csv
  6. borrows → Import borrows.csv
  7. events → Import events.csv
  8. event_assignments → Import event_assignments.csv
  9. activity_logs → Import activity_logs.csv
  10. notifications → Import notifications.csv
⚠️ Ne saute jamais l'étape roles et users en premier ! Les autres tables dépendent d'elles.
